# Dein Kursprojekt

Neben den Übungen baust du über den ganzen Kurs **eine eigene Website**. Die Übungen in den Lektionen sind klein und vorgegeben. Hier entscheidest du selbst, und hier merkst du, was du wirklich kannst.

Alle Dateien deines Projekts kommen in diesen Ordner. Die Startseite heißt `index.html`.

## Das Thema

Nimm etwas, wozu du gern schreibst und Bilder sammelst. Es sollte genug Stoff für drei bis fünf Seiten hergeben. Ein paar Ideen:

- ein Hobby: Kochen, Klettern, Fotografie, Gärtnern
- eine Sammlung: Lieblingsrezepte, Brettspiele, Pflanzen auf deinem Balkon
- ein Fan-Projekt: eine Band, eine Serie, ein Videospiel, ein Verein
- etwas Nützliches: eine Seite für deine WG, deinen Verein oder ein Familientreffen
- eine Seite über dich: Lebenslauf, Projekte, Kontakt

Später in Modul 3 wird die Seite interaktiv, zum Beispiel mit einer Suche, einem Filter oder Favoriten. Es hilft also, wenn dein Thema aus vielen ähnlichen Dingen besteht, etwa Rezepte, Spiele oder Orte.

## Die Meilensteine

| Nach … | Deine Website … |
|---|---|
| Modul 1 – HTML | hat ihren vollständigen Inhalt auf mehreren Seiten, sauber strukturiert, aber noch ohne Gestaltung |
| Modul 2 – CSS | sieht gut aus und funktioniert auf dem Handy genauso wie am Rechner |
| Modul 3 – TypeScript | ist interaktiv und lädt ihre Inhalte aus Daten |

Am Ende jeder Lektion steht in `aufgaben.md` ein **Projekt-Schritt**. Ob du einen Meilenstein erreicht hast, prüft [`check.html`](check.html).

## Ein Tipp zum Schluss

Eine Website ohne CSS sieht nackt aus. Das ist nach Modul 1 völlig in Ordnung, sogar gewollt. Wenn deine Seite ohne jede Gestaltung verständlich und gut gegliedert ist, wird sie mit CSS richtig gut.
